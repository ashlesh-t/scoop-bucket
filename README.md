# scoop-bucket

Scoop bucket for [JobPilot](https://github.com/ashlesh-t/jobpilot) on Windows.

```powershell
scoop bucket add ashlesh-t https://github.com/ashlesh-t/scoop-bucket
scoop install jobpilot
```

This manifest is a thin wrapper — it installs the
[`jobpilot-ai`](https://pypi.org/project/jobpilot-ai/) PyPI package via pipx.
